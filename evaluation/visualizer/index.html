Mem0Sharp Graph Memory Visualizer Guide

This visualizer dynamically loads Mem0Sharp benchmark results directly from evaluation/results/, rendering how memory extraction, deduplication, conflict resolution, reranking, and memory behaviors affect knowledge retrieval.

Graph Views

  • Retrieval & Memory Graph: Connects test questions to the specific memories retrieved from PostgreSQL/pgvector and their extracted knowledge entities.
  • Knowledge Graph: Displays the semantic Subject → Predicate → Object triple network extracted from conversation history.
  • Reasoning Chains: Highlights multi-hop synthesis links and chronological temporal transitions across conversation sessions.

Interactions

  • Click + Drag to pan canvas or reposition nodes.
  • Scroll Wheel / Pinch / Zoom Slider to zoom in/out smoothly.
  • Click on any Node to open the slide-over Inspector with answer comparisons and judge reasoning.
  • Search Bar instantly highlights nodes and their 1-hop neighborhood.
  • Drag & Drop any external evaluation-*.json file onto the window to visualize fresh evaluation runs.
